Section A1

Banner Interaction CSS Failure

Customer report: Clicking "Accept" doesn't save consent. Caused by global rule input[type="checkbox"] { visibility: hidden; }.

Why this happens in real life: WordPress/Shopify themes often reset form inputs globally. Instead of editing vendor code, advise the customer to scope CSS to their forms (e.g. .contact-form input[type="checkbox"]).
